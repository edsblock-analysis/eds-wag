Observed interactive behaviors

header-navigation

Hamburger 'Menu button' opens an off-canvas drawer showing 5 top-level categories (Health, Wellness, Beauty, Community Stories, Buying Guides). Clicking a top-level item drills down to reveal its child categories inline with a 'Back' button to return to the top level. 'Close button' dismisses the drawer. 110 nav items across 2 levels (level-0, level-1).

search

Header search icon toggles a search field (role=search, name=fulltext). Predictive search: min 3 chars (data-cmp-min-length=3), 10 results (data-cmp-results-size=10). AJAX GET to /content/content-hub/us/en/homepage.searchresults.json/_jcr_content/root/customheader/search?fulltext=<q>. Verified endpoint returns JSON array of {title, description, url, lastModified}. Loading indicator + Clear button present.

Homepage hero auto-advances between 5 slides (the 'Viewing' dot indicator moved from slide 0 to 3 to 4 without interaction). Dot navigation links (#carousel-0..4). Custom JS (no jQuery/slick on this component). Each slide = image + headline + CTA link.
